## Technical Details

### FAQ Schema Format

Each FAQ follows this structure:

```json
{
  "@type": "Question",
  "name": "The question users ask",
  "acceptedAnswer": {
    "@type": "Answer",
    "text": "Direct, detailed answer with specifics and facts"
  }
}
```

This is the **schema.org FAQPage** format that AI tools recognize and extract.

### AI Crawler User-Agents

We explicitly allow these crawlers:

- **GPTBot** - OpenAI's crawler for ChatGPT
- **ChatGPT-User** - ChatGPT's browsing feature
- **Google-Extended** - Google's AI training crawler
- **ClaudeBot** - Anthropic's crawler for Claude
- **PerplexityBot** - Perplexity's search crawler
- **Bytespider** - ByteDance AI crawler

### Robots.txt Best Practices

Your `robots.ts` now:
- Allows all crawlers by default (`User-agent: *`)
- Explicitly allows AI crawlers (removes ambiguity)
- Points to sitemap for complete discovery
- Sets proper host for canonicalization
