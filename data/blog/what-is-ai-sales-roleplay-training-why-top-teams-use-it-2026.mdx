## 6. Python Implementation: Real-Time Sales Practice Session & Grader

Below is a complete Python implementation demonstrating how a sales practice turn is processed and graded against value-selling rubrics:

```python
import asyncio
from typing import Dict, Any

class AISalesRoleplayGrader:
    async def grade_rep_turn(self, rep_utterance: str, buyer_objection: str) -> Dict[str, Any]:
        """
        Evaluates rep objection handling against value-selling frameworks in real time.
        """
        await asyncio.sleep(0.04) # Simulated 40ms grading inference

        # Check for value anchors and ROI proof points
        roi_keywords = ["roi", "cost", "latency", "sub-200ms", "savings", "efficiency", "metrics"]
        anchors_found = [k for k in roi_keywords if k in rep_utterance.lower()]

        value_score = min(10.0, len(anchors_found) * 2.5)
        did_ask_next_step = "?" in rep_utterance and ("thursday" in rep_utterance.lower() or "friday" in rep_utterance.lower() or "time" in rep_utterance.lower())

        return {
            "buyer_objection": buyer_objection,
            "rep_response": rep_utterance,
            "value_anchor_score": value_score,
            "closed_for_calendar_slot": did_ask_next_step,
            "coaching_feedback": "Strong ROI framing. Ensure you lock in a specific time on Thursday." if did_ask_next_step else "Good explanation, but remember to ask for a firm meeting slot."
        }
```
