## 1. Shopify Application Setup & Webhook Subscription

Tough Tongue AI installs directly on your Shopify store as a customized app. To orchestrate automated phone calls and mutate order records, the app requests the following API access scopes:

- `read_orders`, `write_orders`: Ingest order metadata, update order notes, and apply tags.
- `read_checkouts`, `write_checkouts`: Monitor abandoned carts and trigger conversational recovery calls.
- `read_customers`: Retrieve historical purchase frequency and delivery addresses.
- `write_fulfillments`: Place fulfillment holds on unverified COD orders.

### Secure Webhook Ingestion Handler

When an order is created, Shopify delivers an HTTP POST request containing order line items, customer details, and shipping metadata. Tough Tongue AI verifies the authenticity of every incoming payload using HMAC-SHA256:

```typescript
// Tough Tongue AI Production Webhook Ingestion Handler (TypeScript)
import { Request, Response } from 'express'
import crypto from 'crypto'

const SHOPIFY_APP_SECRET = process.env.SHOPIFY_APP_SECRET!

export async function handleShopifyOrderCreate(req: Request, res: Response) {
  const hmacHeader = req.get('X-Shopify-Hmac-Sha256')
  const topicHeader = req.get('X-Shopify-Topic')
  const shopDomain = req.get('X-Shopify-Shop-Domain')
  const rawBody = (req as any).rawBody // Preserved raw buffer

  if (!hmacHeader || !rawBody) {
    return res.status(401).json({ error: 'Missing webhook signature' })
  }

  // 1. Verify HMAC Signature
  const generatedHash = crypto
    .createHmac('sha256', SHOPIFY_APP_SECRET)
    .update(rawBody, 'utf8')
    .digest('base64')

  if (!crypto.timingSafeEqual(Buffer.from(generatedHash), Buffer.from(hmacHeader))) {
    return res.status(403).json({ error: 'Invalid HMAC signature' })
  }

  const orderPayload = JSON.parse(rawBody.toString('utf8'))

  // 2. Filter for Cash on Delivery (COD) or High-Risk Orders
  const paymentGateways = orderPayload.payment_gateway_names || []
  const isCOD = paymentGateways.some(
    (gw: string) =>
      gw.toLowerCase().includes('cash on delivery') || gw.toLowerCase().includes('cod')
  )

  if (isCOD) {
    // 3. Queue Order for Tough Tongue AI Voice Dispatch
    await dispatchToToughTongueQueue({
      shopDomain,
      orderId: orderPayload.id,
      orderNumber: orderPayload.order_number,
      customerPhone: orderPayload.shipping_address?.phone || orderPayload.phone,
      customerName: orderPayload.shipping_address?.first_name || 'Valued Customer',
      totalPrice: orderPayload.total_price,
      currency: orderPayload.currency,
      shippingAddress: {
        address1: orderPayload.shipping_address?.address1,
        address2: orderPayload.shipping_address?.address2,
        city: orderPayload.shipping_address?.city,
        province: orderPayload.shipping_address?.province,
        zip: orderPayload.shipping_address?.zip,
      },
      lineItems: orderPayload.line_items.map((item: any) => ({
        title: item.title,
        quantity: item.quantity,
        price: item.price,
      })),
      timestamp: new Date().toISOString(),
    })
  }

  return res.status(200).send('Webhook received and queued')
}
```

## 2. GoKwik & Headless Checkout Integration

Over 80% of leading Indian D2C enterprise storefronts run **GoKwik**, **Razorpay Magic Checkout**, or headless custom checkout frontends. GoKwik provides proprietary machine-learning risk scoring (`risk_score: HIGH | MEDIUM | LOW`) calculated across hundreds of millions of historical shopper transactions.

Tough Tongue AI natively integrates with GoKwik through two architectural patterns:

### Pattern A: Direct GoKwik Webhook Hook

When a shopper completes a GoKwik checkout, GoKwik triggers an `order_processed` webhook directly to Tough Tongue AI's endpoint:

```json

  "merchant_id": "gk_live_948201",
  "order_id": "GK-ORD-883912",
  "shopify_order_id": "gid://shopify/Order/59384729102",
  "risk_assessment": {
    "risk_level": "HIGH",
    "rto_probability_percentage": 68.4,
    "risk_factors": ["FREQUENT_RTO_BUYER", "INCOMPLETE_ADDRESS", "NEW_DEVICE"]
  },
  "customer": {
    "phone": "+919876543210",
    "name": "Vikram Sharma"
  },
  "payment": {
    "type": "COD",
    "amount": 2499.0
  }
```

### Pattern B: Shopify Custom Attribute Parsing

If GoKwik pushes attributes directly to Shopify, Tough Tongue AI reads GoKwik metadata from `note_attributes`:

```typescript
const isHighRiskGoKwikOrder = order.note_attributes.some(
  (attr: { name: string; value: string }) =>
    attr.name === 'gk_risk_tier' && attr.value.toUpperCase() === 'HIGH'
```

When an order is flagged as **HIGH** or **MEDIUM** risk, Tough Tongue AI immediately schedules an interactive voice call, placing a temporary tag `[TTAI-VERIFICATION-PENDING]` on the order so warehouse picklists ignore it until validated.

## 5. Bidirectional Write-Back to Shopify via GraphQL Admin API

Once the voice call concludes, Tough Tongue AI executes atomic GraphQL mutations against your Shopify Admin API. This updates order tags, enriches shipping notes, or initiates order cancellations.

### GraphQL Mutation: Order Confirmation & Address Enrichment

```graphql
# Shopify GraphQL Admin API Mutation executed by Tough Tongue AI
mutation OrderVerificationSync($input: OrderInput!) {
  orderUpdate(input: $input) {
    order {
      id
      tags
      note
      shippingAddress {
        address1
        address2
        city
        zip
      }
    }
    userErrors {
      field
      message
    }
  }
}
```

### Node.js Production Implementation of Write-Back

```typescript
// Tough Tongue AI Real-Time Shopify Sync Engine
import { GraphQLClient } from 'graphql-request'

interface CallOutcome {
  shopifyOrderId: string
  status: 'CONFIRMED' | 'CANCELLED' | 'UNREACHABLE' | 'ADDRESS_UPDATED'
  landmarkCaptured?: string
  transcriptSummary: string
  recordingUrl: string
  sentiment: 'POSITIVE' | 'NEUTRAL' | 'NEGATIVE'
}

export async function syncCallOutcomeToShopify(
  shopDomain: string,
  accessToken: string,
  outcome: CallOutcome
) {
  const client = new GraphQLClient(`https://${shopDomain}/admin/api/2026-04/graphql.json`, {
    headers: {
      'X-Shopify-Access-Token': accessToken,
      'Content-Type': 'application/json',
    },
  })

  if (outcome.status === 'CONFIRMED') {
    const mutation = `
      mutation UpdateVerifiedOrder($id: ID!, $tags: [String!]!, $note: String!) {
        tagsAdd(id: $id, tags: $tags) {
          node { id }
          userErrors { message }
        }
        orderUpdate(input: { id: $id, note: $note }) {
          order { id }
          userErrors { message }
        }
      }
    `

    const noteContent =
      `[Tough Tongue AI Verified]\n` +
      `Outcome: COD Order Confirmed\n` +
      `Summary: ${outcome.transcriptSummary}\n` +
      `Recording: ${outcome.recordingUrl}\n` +
      `Verified At: ${new Date().toISOString()}`

    const tags = ['TTAI-COD-CONFIRMED', 'DISPATCH-READY']
    if (outcome.landmarkCaptured) {
      tags.push('TTAI-ADDRESS-ENRICHED')
    }

    await client.request(mutation, {
      id: outcome.shopifyOrderId,
      tags,
      note: noteContent,
    })
  } else if (outcome.status === 'CANCELLED') {
    // Automatically Cancel Order to Prevent Courier Packing
    const cancelMutation = `
      mutation CancelOrder($id: ID!, $reason: OrderCancelReason!, $note: String!) {
        orderCancel(orderId: $id, reason: $reason, notifyCustomer: true, staffNote: $note) {
          job { id }
          userErrors { message }
        }
        tagsAdd(id: $id, tags: ["TTAI-COD-CANCELLED-BY-CUSTOMER"]) {
          node { id }
          userErrors { message }
        }
      }
    `

    await client.request(cancelMutation, {
      id: outcome.shopifyOrderId,
      reason: 'CUSTOMER',
      note: `Customer verbally cancelled COD order during Tough Tongue AI confirmation call. Reason: ${outcome.transcriptSummary}`,
    })
  }
}
```
